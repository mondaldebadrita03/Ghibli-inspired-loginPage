# 🌿 Ghibli-Inspired Login Page

A simple and cozy **Ghibli-inspired login page** built using **HTML and CSS**.

This was one of my early projects while learning the fundamentals of web development. I created it to practice webpage structure, CSS styling, layouts, positioning, colors, typography, and creating visually appealing user interfaces.

> 🌸 This project is a static frontend design. It does not include JavaScript, database connectivity, or backend authentication.

## ✨ Features

* 🌿 Ghibli-inspired visual design
* 🔐 Styled login form
* 🎨 Custom background and UI styling
* 📐 CSS-based layout and positioning
* 📱 Responsive design
* ✨ Simple and beginner-friendly implementation

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📂 Project Structure

```text
ghibli-login-page/
│
├── index.html      # Main login page
├── style.css       # Styling and layout
└── README.md       # Project documentation
```

## 🚀 How to Run

No installation or additional setup is required.

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder.

3. Open `index.html` in your browser.
